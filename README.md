# CodeAlpha_StockPortfolioTracker
A Python-based Stock Portfolio Tracker that calculates investment value and generates portfolio reports.
Stock Portfolio Tracker

About the Project

This project was created to practice Python programming concepts through a real-world use case. The Stock Portfolio Tracker allows users to enter stock names and quantities, then calculates the total investment value based on predefined stock prices.

While building this project, I explored how dictionaries, loops, conditional statements, and file handling can be used together to create a useful application.

Features

- Display available stocks and their prices
- Accept user input for stock selection and quantity
- Calculate investment value for each stock
- Generate a portfolio summary
- Find the highest investment stock
- Save the portfolio report to a text file

Technologies Used

- Python
- Dictionaries
- Loops
- Conditional Statements
- File Handling
